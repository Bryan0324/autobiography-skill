# 自傳成長編織器（Autobiography Growth Weaver）

這是一個協助 AI 撰寫自傳的 Skill，透過具體、可查證的故事呈現個人成長，而不是重複履歷上的經歷與成果。

## Repo 結構

```text
autobiography-growth-weaver/
├── README.md
├── README.zh-TW.md
├── LICENSE
└── skills/
    └── autobiography-growth-weaver/
        ├── SKILL.md
        └── SKILL.zh-TW.md
```

- `SKILL.md`：英文版 Skill 指令。
- `SKILL.zh-TW.md`：繁體中文版 Skill 指令。
- `README.md`：英文版專案介紹與使用說明。
- `README.zh-TW.md`：繁體中文版專案介紹與使用說明。
- `LICENSE`：MIT 授權條款。

## 功能

- 偵測成長主張是否缺少具體故事。
- 檢查故事鏈：場景 → 原本的假設 → 遇到阻力 → 採取行動 → 證據 → 反思 → 後續延伸。
- 在追問作者前，先搜尋可取得且經授權的資料。
- 區分可查證事實，以及只有作者本人能確認的動機與感受。
- 在證據不足時提出少量、精準的問題。
- 協助比較不同版本、規劃敘事、診斷段落與修改文字，同時避免捏造事實。

## 使用方式

將 `skills/autobiography-growth-weaver/SKILL.zh-TW.md` 提供給支援自訂 Skill／指令的 AI 工具，或依該工具的要求安裝到指定目錄。

可以一併提供不同版本的自傳、履歷／經歷表，以及經授權可參考的專案報告、實驗紀錄、原始碼、README、簡報或反思筆記。AI 應先檢查現有證據，再針對仍未解決的故事缺口提出精準問題。

## 提示詞範例

- 「比較這兩份自傳，找出哪些成長主張缺少具體故事。」
- 「檢查這篇自傳中缺乏事件支撐的心得。先搜尋我提供的專案資料，再只詢問補足缺口所需的問題。」
- 「修改這篇自傳，讓每個重要的思考轉變都有具體事件支撐。」

## 設計原則

1. **成長優先，不重複履歷。**
2. **先找證據，再補寫故事。**
3. **只針對重要缺口提問。**
4. **不捏造事件、動機、情緒或結果。**
5. **保留作者本人的聲音。**
